# 川西塔公三日自驾 · 2026

2026年8月28日至30日，从成都武侯出发，经雅安、康定、S434、塔公草原、新都桥和折多山返回成都的交互式旅行计划。

网页包含：

- 站内加载的地图组件，不依赖外部 CDN；
- 卫星、地形、道路和“仅看路线”四种底图模式；
- 每日路线高亮、路线全览、当前位置、全屏地图和节点详情抽屉；
- 全程视图把完全重合的去返程线路左右分轨，返程使用蓝色虚线，避免后绘制线路遮挡前一日线路；
- 地图节点一键跳转高德导航，支持按天与历史重复度着色；
- 基于历史 GPX 的路段重复度显示；
- 小时级行程、硬截止时间和雨天删减顺序；
- 塔公、塔公寺、新都桥和折多山玩法；
- 两晚住宿、高反下撤方案与出发清单。

核心网页资源和压缩照片会缓存在手机浏览器，首次打开后再次查看更快；外部卫星或道路瓦片仍取决于当时网络，网络较差时可切换“仅看路线（最快）”。

网页源文件位于 [`docs/`](./docs/)。路线是行前建议，实际驾驶以当日天气、导航和官方交通管制为准。
